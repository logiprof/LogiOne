# Guide enseignant LogiOne

## Évaluation papier

1. **LogiNotes → Évaluations.** Créez l'évaluation : classe, semestre, date, points totaux, et le **cours Sensei** si un bonus ou un malus de progression s'applique.
2. Sous le formulaire, le panneau **Progression LogiProgress** montre une lecture provisoire, élève par élève :
   - leçons terminées sur leçons exigées ;
   - proposition : **Bonus +1**, **Malus −2** ou **À vérifier**.
3. Au moment choisi, cliquez **Actualiser et valider la progression**. Vous pouvez changer une décision (bonus, malus ou exemption à 0) : le motif est alors obligatoire. Le +1 ou le −2 est inscrit dans la colonne « ajustement », même si le test n'est pas encore corrigé.
4. Saisissez les **points obtenus aux questions**. La note tient compte de l'ajustement une seule fois.
5. Si vous enregistrez des notes sans avoir validé la progression, le relevé est **figé automatiquement**. Il ne change plus, même si un élève termine ses leçons plus tard. Ses propositions restent à valider : bouton **Valider les décisions de ce relevé figé**.
6. Pour corriger un relevé validé, utilisez **Réviser**, avec un motif. Une nouvelle version est créée, l'ancienne reste consultable.

« À vérifier » ne donne jamais de malus. Ce cas se présente pour un quiz rendu mais pas encore corrigé, un élève non relié à son compte ou un cours sans leçon exigée.

## Évaluation numérique

1. **LogiExam.** Créez l'évaluation comme d'habitude. À l'enregistrement, une **fiche LogiNotes** est créée automatiquement, sans note. Si le groupe Sensei n'est relié à aucune classe, la fiche reste en attente : complétez-la depuis l'encadré « Fiche LogiNotes ». Vous pouvez aussi la rattacher à une fiche existante, pour un rattrapage.
2. Dans l'étape **Préparer**, validez la progression comme pour le papier. Le bonus ou le malus est appliqué à chaque copie remise, et n'est plus remis à zéro.
3. Corrigez puis finalisez comme d'habitude. Rien n'est encore envoyé à LogiNotes.
4. Dans l'étape **Résultats**, cliquez **Publier les résultats dans LogiNotes**.
   - Seules les copies finalisées partent ; les autres partiront à la publication suivante.
   - Une copie arrêtée pour sorties répétées du mode sécurisé arrive dans LogiNotes en triche, avec la note 1.
5. Pour modifier une note publiée, **rouvrez la correction dans LogiExam**, corrigez, finalisez, puis republiez. LogiNotes garde l'ancienne note jusqu'à la nouvelle publication, avec la mention « en cours de révision ». Le PDF élève indique la révision publiée.

Dans LogiNotes, les notes publiées depuis LogiExam sont en lecture seule.

## Changement de classe

Un élève qui change de classe garde toutes ses données. Il reste visible dans les évaluations, relevés et exports de son ancienne classe, avec la mention « désormais en … ». Seules les nouvelles évaluations utilisent sa nouvelle classe.

## LogiClass

LogiClass fonctionne comme avant : imports, situations à traiter, communications, rapports. Les envois externes restent manuels. Ce module n'échange encore aucune donnée avec les trois autres.
